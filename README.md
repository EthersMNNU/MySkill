# 批判性思维作业 AI 辅助批阅 — Claude Code Skills

一套面向高校人文/社科课程的 AI 辅助作业批阅体系。核心理念：**不是 AI 教人评分，是人教会 AI 什么是好的批判性思维。**

## 适用场景

- 课程作业要求学生观看视频/阅读文本后撰写反思性文章
- 评分目标不是检验信息整理能力，而是检验学生"看完之后脑子里发生了什么"
- 教师已有明确的评价理念，需要 AI 作为协作者加速批阅流程

## 评分框架

四级认知递进，从低到高：

| 层级 | 核心问题 | 分数区间 |
|------|----------|----------|
| 层级一 · 记述 | 有没有看懂、记住、用自己的话讲出来 | 75–83 |
| 层级二 · 解读 | 有没有拆解、用自己的框架重新拼起来 | 80–88 |
| 层级三 · 批判 | 有没有质疑——有依据地指出问题 | 88–96 |
| 层级四 · 反思 | 有没有从外部审视拉回到自身——承认被塑造 | 93–100 |

评分从鼓励的视角出发：先找学生最亮的地方，再从那里出发确定分数。

## 文件说明

| 文件 | 用途 |
|------|------|
| `指向批判与反思的作业评分标准.md` | 四级递进评分标准全文，含语言判断、扣分项、AI辅助写作识别规则 |
| `评语写作标准.md` | 评语写作规范：三条必含内容、禁止事项、核实步骤 |
| `批阅观后感作业.md` | 七步批阅流程：读取标准→评分→双库校准→写评语→核实→输出 |
| `观后感批阅-标杆案例.md` | 7个标杆案例，覆盖四个层级，用于评分参照校准 |
| `观后感批阅-边界案例.md` | 人机分歧纠正记录，积累误判模式防止重复出错 |

## 使用方式

1. 将本仓库克隆到项目目录下的 `.claude/skills/` 路径
2. 在项目根目录放置 `CLAUDE.md`，引用 skills 文件
3. Claude Code 会自动加载这些 skill，按其中的标准执行批阅

批阅操作约束：
- 每次最多批阅 5 份作业，逐份处理
- 评语使用第三人称，三条必含：哪里好、哪里不好、怎么做能更好
- 评语写完必须核实具体内容（案例名、地名、数据、引文回溯原文确认）

## 设计原则

- **主语永远是人，不是 AI。** 叙事逻辑：我一直这样教批判性思维 → AI 来了 → 我把 AI 变成了这件事的加速器和精密化工具
- **核心反转：不是 AI 教人评分，是人教会 AI 什么是好的批判性思维。** AI 初评一塌糊涂，教师将评价理念教会 AI，经多轮互校后 AI 成为协作者
- **用具体证据替代概括性声称** — 让数据说话、让对比可见
- **诚实提及风险** — AI 评分需人工复核，存在向上高判和向下低判两个系统性偏差
- **语言诚实、朴素、精确** — 避免比喻性术语、评论员语体、宣传语体、学术套话

## 注意事项

- 本仓库中的学生姓名已做匿名化处理
- 评分标准全文为评分唯一依据，速查表仅为辅助——每次批阅前必须重读全文
- AI 评分存在两个系统性偏差：(1) 向上高判——学术语言流畅性被误判为独立思考；(2) 向下低判——隐性反思因无显性自我标记被误判为批判
- 这些 skill 是为特定课程定制的。其他课程使用前需调整评分标准、标杆案例和边界案例
